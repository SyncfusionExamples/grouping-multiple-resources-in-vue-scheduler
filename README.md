# Grouping Multiple Resources in Vue Scheduler

This repository demonstrates how to group multiple resources in the [Vue Scheduler](https://www.syncfusion.com/vue-components/vue-scheduler), including defining resource data sources, mapping appointments, and organizing resources hierarchically and by date. It provides practical examples and best practices for building efficient and structured scheduling solutions using resource grouping in Vue applications.

## Features

- Group multiple resources by date or hierarchically
- Define custom group data sources
- Map appointments to grouped resources
- Responsive design with Bootstrap 5 styling

## How to run this application?

To run this application, you need to first clone the `grouping-multiple-resources-in-vue-scheduler` repository and then navigate to its appropriate path where it has been located in your system.

To do so, open the command prompt and run the below commands one after the other.

```
git clone grouping-multiple-resources-in-vue-scheduler

cd grouping-multiple-resources-in-vue-scheduler
```

### Installing

Once done with downloading, next you need to install the necessary packages required to run this application locally. The `npm install` command will install all the needed Vue packages into your current project and to do so, run the below command.

```
npm install
```

### Running on development server

Run `npm run serve` command for a dev server. Navigate to `http://localhost:8080/`. The app will automatically reload if you change any of the source files.
